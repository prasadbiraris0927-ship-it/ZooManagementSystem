#  Zoo Management System

A console-based Zoo Management System built with Java to practise Object-Oriented Programming (OOP), collections, and input validation.

##  Features

- **Add Animals:** Add Lions and Elephants.
- **Display Animals:** View all registered animals and their details.
- **Search Animals:** Find an animal using its unique ID.
- **Update Health Status:** Update an animal's health status.
- **Remove Animals:** Remove an animal by ID.
- **Input Validation:** Validate animal IDs, names, ages, gender, and health status.
- **Duplicate ID Prevention:** Prevent duplicate IDs across animal types.

##  How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/prasadbiraris0927-ship-it/ZooManagementSystem.git
   ```

2. Open the project in IntelliJ IDEA.
3. Ensure Java 17 or a compatible newer version is configured.
4. Allow Maven to load the project dependencies.
5. Run `Main.java`.
